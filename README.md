# ⏱️ Pomodoro Timer

A simple and visually appealing Pomodoro Timer built with Python's `tkinter` library. It helps you manage time using the Pomodoro Technique — 25 minutes of focused work followed by short breaks.

## 🍅 Features

- 25-minute work sessions
- 5-minute short breaks
- 20-minute long breaks after every 4 work sessions
- Countdown timer with visual update
- Checkmarks to show completed work sessions
- Reset and start functionality

## 🎨 UI

- Built with `tkinter`
- Custom colors and fonts
- Includes a tomato-themed image to match the Pomodoro theme

## 🛠️ Dependencies

Only standard Python libraries are used:

- `tkinter`
- `math`

No external installations required.
